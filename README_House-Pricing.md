# House Price Prediction using Machine Learning

A regression project that predicts the selling price of a house from its size, number of rooms, age and location. The project trains and compares four regression models, automatically selects the best one, saves it to disk, and provides an interactive command-line tool for predicting the price of a new house.

## Project Overview

Estimating the fair price of a house is a classic regression problem. This project takes five property features and predicts the price in US dollars:

- Square footage
- Number of bedrooms
- Number of bathrooms
- House age (in years)
- Location category (Rural, Suburban or Urban)

Instead of relying on a single algorithm, the training script fits four different models, evaluates each one on the same held-out test set using the same metrics, and saves the model with the highest R2 score. The prediction script then loads that saved model and answers price queries interactively.

---

## Key Highlights

- Compares 4 regression models: Linear Regression, Ridge Regression, Random Forest and Gradient Boosting.
- Best model: Ridge Regression with an R2 score of 0.9854 on the test set.
- Mean absolute error of about $15,430 on the best model.
- Preprocessing pipeline with one-hot encoding for the categorical Location feature.
- Cross-validated R2 (CV R2) reported for every model to check stability.
- Best model is saved automatically as a `.pkl` file and reused by the prediction script.
- Interactive prediction tool with default values, so a user can press Enter to accept a default.

## How It Works

```
 h_prices.csv
      |
      v
 Train/Test Split (24 / 6)
      |
      v
 Preprocessing Pipeline
  - One-hot encode Location
  - Pass numeric features
      |
      v
 Train 4 Models
  Linear | Ridge | Random Forest | Gradient Boosting
      |
      v
 Evaluate: R2, MAE, RMSE, Cross-validated R2
      |
      v
 Select best model by R2 (Ridge Regression)
      |
      v
 Save as house_price_model.pkl
      |
      v
 prediction.py loads the model and predicts new house prices
```

### Why one-hot encoding?

Machine learning models need numbers. The Location column holds text (Rural, Suburban, Urban), so it is converted into separate 0/1 columns. This avoids implying a false order such as Rural < Suburban < Urban.

### Why compare several models?

Different algorithms fit data differently. Linear and Ridge Regression assume a straight-line relationship, which works well for house prices driven mainly by size. Random Forest and Gradient Boosting capture non-linear patterns but need more data. Comparing them on the same test set shows which approach suits this dataset.

## Training the Models

```bash
python training_model.py
```

The script:

1. Loads `h_prices.csv`.
2. Splits the data into 24 training and 6 test rows.
3. Builds the preprocessing pipeline.
4. Trains Linear Regression, Ridge Regression, Random Forest and Gradient Boosting.
5. Prints a comparison table with R2, MAE, RMSE and cross-validated R2.
6. Prints actual versus predicted prices for the test set.
7. Saves the best model to `house_price_model.pkl`.

**Sample output**

**Using the model in your own code**

```python
import joblib
import pandas as pd

model = joblib.load("house_price_model.pkl")

new_house = pd.DataFrame([{
    "SquareFootage": 2056,
    "Bedrooms": 3,
    "Bathrooms": 3,
    "Age": 2,
    "Location": "Suburban"
}])

print(model.predict(new_house))
```

> The column names must match those used in `training_model.py`. Check the script if your column names differ.

## Results

### Model comparison (6 test samples)

| Model | R2 | MAE | RMSE | CV R2 |
|---|---|---|---|---|
| Linear Regression | 0.9788 | $20,553.10 | $24,058.58 | 0.9771 |
| **Ridge Regression** | **0.9854** | **$15,429.58** | **$19,950.88** | 0.9733 |
| Random Forest | 0.9649 | $20,961.67 | $30,923.00 | 0.9744 |
| Gradient Boosting | 0.9769 | $18,163.14 | $25,123.83 | 0.9626 |

### Actual versus predicted prices (test set)

| Actual | Predicted | Error |
|---|---|---|
| $455,000 | $467,125 | +$12,125 |
| $365,000 | $369,904 | +$4,904 |
| $405,000 | $369,125 | -$35,875 |
| $615,000 | $607,499 | -$7,501 |
| $710,000 | $680,565 | -$29,435 |
| $205,000 | $202,263 | -$2,737 |

### Metric definitions

| Metric | Meaning |
|---|---|
| R2 | Share of price variation explained by the model. 1.0 is perfect. |
| MAE | Average size of the prediction error in dollars. |
| RMSE | Like MAE but penalises large errors more heavily. |
| CV R2 | Average R2 across cross-validation folds, showing how stable the model is on different slices of data. |

## Result Analysis

- **Ridge Regression performed best**, with the highest R2 (0.9854) and the lowest MAE and RMSE.
- Ridge reduced the mean absolute error by about **25%** compared with plain Linear Regression ($20,553 down to $15,430).
- The strong performance of the linear models suggests that price in this dataset depends largely on a roughly linear relationship with features such as square footage.
- Random Forest had the lowest R2 and the highest RMSE. Tree-based models usually need much more data than 24 training rows to show their strength.
- The largest single error was $35,875 (about 8.9% of that house's actual price), and all six test predictions were within about 9% of the true price.
- Cross-validated R2 values are all above 0.96, which indicates consistent behaviour across folds.

---

## Limitations

- **Very small dataset.** Only 30 rows (6 for testing) means the metrics can change noticeably with a different split. The R2 values should be treated as indicative, not conclusive.
- Only five features are used. Real prices also depend on lot size, neighbourhood quality, condition, amenities and market timing.
- Location has only three categories, which is a coarse description of where a house is.
- The model should not be used for real financial or valuation decisions.
